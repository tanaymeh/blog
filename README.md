# blog
This repository houses my blog.

## Post summaries

Add a plain-text paragraph under `summary` in the YAML front matter of a post:

```yaml
summary: >-
  Explain what the post covers and what the reader will learn.
```

The summary appears on the post index, in the article header, and in link previews.
In the blog editor, you can add it under **Advanced front matter**. If a post has
no summary or description, the index uses a short excerpt from the article.

The blog originally used [Kagami](https://github.com/kamikat/jekyll-theme-kagami).
